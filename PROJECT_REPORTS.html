Title of Project : Automated Web-Based Print Shop Management and Direct Spooling System
Progress Summary

The primary focus during Phase 1 (up to October 2026) was problem formulation, Software Requirements Specification (SRS), architectural design, relational schema modeling, and foundational prototype development. The project addresses systemic delays and privacy issues in traditional campus photocopy shops resulting from manual USB pen-drive handling and unorganized messaging app file transfers. A 3-tier decoupled architecture was formulated comprising a modern React/Vite customer interface, an asynchronous FastAPI REST API backend, and an SQLAlchemy ORM database. A secure document ingestion service supporting uploads up to 50MB was built alongside client-side PDF rendering via PDF.js. In addition, an automated dynamic tiered pricing engine was developed to handle page-range parsing, duplex calculation, and B/W vs. color printing modes.

Tasks Completed
  • Requirement Engineering & Feasibility Analysis: Conducted campus workflow survey; compiled SRS defining functional requirements (contactless upload, live pricing, order tracking) and security constraints (document privacy).
  • System Architecture & High-Level Design: Designed service-oriented decoupled architecture connecting React customer portal, FastAPI REST layer, SQLite/PostgreSQL relational database, and background print queue.
  • Relational Database Modeling: Engineered database models in models.py including Shop (multi-tenancy, rates, status), Order (customer metadata, pickup code, payment status), and OrderItem (multi-file tracking).
  • Secure File Ingestion Service: Developed file_service.py to handle multipart streaming uploads, MIME-type verification, 50MB upload limits, and cryptographic filename hashing to prevent path traversal attacks.
  • Dynamic Tiered Pricing Engine: Implemented mathematical pricing logic (pricing.py) incorporating volume tiers (1–10, 11–20, 21+ pages), custom page-range parsing (e.g. "1-5, 8, 12-14"), and duplex configurations.
  • Frontend PDF Preview Portal: Built interactive web interface using React and pdfjs-dist for instant client-side thumbnail generation, orientation detection, and total page validation.
Tasks in Progress
  • Asynchronous Print Queue Worker: Developing background worker thread (print_queue.py) implementing FCFS job scheduling and state management (QUEUED → PRINTING → PRINTED).
  • Hardware Spooling Integration: Researching silent command-line printing via SumatraPDF and PyMuPDF document composition on Windows printers.
  • Shopkeeper Administration Portal: Designing dashboard for shopkeepers to manage store status, custom pricing, and hardware printer mappings.
  • Payment Gateway Integration: Implementing Razorpay test API endpoints and order validation workflows.

Title of Project : Automated Web-Based Print Shop Management and Direct Spooling System
Progress Summary

Phase 2 (November 2026) achieved complete system implementation, hardware driver integration, payment verification, and multi-tenant administrative control. The autonomous background print worker (print_queue.py) was fully implemented with individual file-level fault tolerance. Using PyMuPDF (fitz) and SumatraPDF, a high-precision document imposition engine was developed to handle N-up multi-page layouts (2, 4, 6, 9, 16 pages/sheet), duplex parity compensation (inserting blank trailing pages to prevent cross-document leakage), and dynamic cover slip generation with encrypted verification QR codes. Razorpay payment verification was secured via HMAC-SHA256 signature hashing. A comprehensive Shopkeeper Portal and customer live order tracking page with 6-character pickup codes were deployed alongside automated 24-hour file shredding routines.

Tasks Completed
  • Autonomous Background Print Spooler: Implemented multi-threaded worker (print_queue.py) with 2-second polling, FCFS dispatch, atomic status updates, and fault recovery preventing duplicate file re-prints.
  • PyMuPDF Imposition & N-up Layout Engine: Created automated PDF composer (windows_printer.py) that dynamically imposes pages into N-up grids, extracts selected subsets, and handles page dimensions (A4, A3, Letter).
  • Hardware Spooling & Driver Automation: Successfully integrated SumatraPDF command-line execution for silent, dialog-free printing to configured Windows physical printers with duplex and color channel routing.
  • Dynamic QR Code Cover Slip Generator: Integrated automated receipt/slip generation producing order metadata, pickup credentials, and scannable QR codes for counter verification.
  • Razorpay Payment Security: Implemented server-side payment verification utilizing cryptographic HMAC-SHA256 hashing to confirm transaction legitimacy before queuing jobs.
  • Shopkeeper Portal & Customer Tracker: Deployed live operational dashboard (ShopDashboard.jsx) for queue monitoring and manual re-prints, plus customer tracking UI (TrackOrderPage.jsx) with secure pickup codes.
  • Automated Data Retention & Privacy Engine: Engineered automated lifecycle worker purging sensitive user documents immediately after successful printing or following a strict 24-hour expiration threshold.
Tasks in Progress
  • Final Capstone Thesis & Documentation: Writing comprehensive project report, system architecture diagrams, UML state/sequence charts, and OpenAPI documentation.
  • Pilot Campus Testing & Evaluation: Deploying the system across campus print counters to benchmark operational latency reduction and printer throughput under peak loads.
  • Production Deployment & Service Daemonizing: Packaging the background queue daemon as an auto-recovering Windows Service (via NSSM) and configuring production environment variables.
